## 试玩调整范围

自动路线使用精确瞄准，证明关卡可通关，不代表玩家通常完成速度。首版难度偏休闲，后续根据玩家瞄准失误、剩余时间和道具使用情况调整。

本轮未单独启动外部 Chrome 和 Edge，也未进行具体电脑型号的帧率基准。首版按电脑浏览器交付，手机操作、安装包和联网排行不在本轮范围。
