# 黄金矿工

中文单人黄金矿工游戏，包含 20 个固定关卡、关间商店、三种道具、合成音乐和本地存档。

## 在线游玩

GitHub Pages 地址：[打开黄金矿工](https://jyyang621.github.io/gold-miner/)。朋友打开链接即可游玩，无需安装，也不需要本地服务。每个人的进度独立保存在自己的浏览器中。

推送到 `main` 后，GitHub Actions 会运行测试、构建并更新网页。首次部署需在仓库 Settings → Pages 中选择 GitHub Actions 作为发布来源。

## 开始游戏

Windows 下双击 [开始游戏.cmd](./开始游戏.cmd)，脚本会启动本机服务并打开浏览器。游玩时保留服务窗口，关闭窗口或按 Ctrl+C 可以停止服务。

重复双击会直接打开已经运行的本游戏，不再报端口占用。如果 8080 被其他程序占用，启动器会自动选择 8081 至 8099 中的可用端口，不会关闭其他程序。

也可以在项目目录运行：

```powershell
node scripts/serve.mjs
```

默认访问 http://127.0.0.1:8080/ ，若发生端口切换，以窗口显示的实际地址为准。本地交付目录包含 `dist` 构建产物；从 GitHub 获取源码后，请先按下方命令安装依赖并构建。构建完成后，本地游玩无需联网。需要 Node.js；启动脚本会优先使用系统 Node，否则尝试本机 Codex 配套的 Node。

## 操作与规则

| 操作 | 按键或按钮 |
| --- | --- |
| 下钩 | 空格、↓，或点击矿区 |
| 炸掉钩中物品 | ↑、B，或炸药按钮 |
| 暂停与继续 | Esc、P，或暂停按钮 |
| 提前结束 | 达标且抓钩回到起点后，点击收工结算 |
| 开关声音 | 顶部声音按钮 |

每关 60 秒。矿物必须拉回地面才计分，最后时刻仍在途中不算收入。每关有独立收入目标，钱包跨关保留，商店消费不扣累计成绩。力量药水和钻石增值券只作用于下一关，炸药库存可跨关保留。

切换窗口会自动暂停，回来后手动继续。失败重试恢复进关时的钱包、道具和矿场布局。挖矿途中退出或刷新，也从进关状态重新开始；商店购买会立即保存。

存档保存在当前浏览器的当前站点地址下，换浏览器、端口或清理站点数据后不会共享。浏览器禁用存储时仍可游玩，但进度无法持久保存。

## 开发与构建

开发环境使用 Node.js 22.18 或以上，以及 pnpm 11。

```powershell
pnpm install
pnpm dev
pnpm test
pnpm build
```

开发地址为 http://127.0.0.1:5173/ ，构建输出为 `dist`。也可在已有依赖的环境中直接运行 `node node_modules/vite/bin/vite.js`。`pnpm build` 包含 TypeScript 检查。

## 代码结构

| 文件 | 用途 |
| --- | --- |
| `src/main.ts` | 页面流程、商店、钱包、存档与输入衔接 |
| `src/engine.ts` | 抓钩状态、连续路径碰撞、收入与时间结算 |
| `src/renderer.ts` | Canvas 卡通矿场、角色、矿物和粒子 |
| `src/levels.ts` | 20 关固定布局、数值和道具增值计算 |
| `src/audio.ts` | Web Audio 合成音效和背景音乐 |
| `src/storage.ts` | 本地存档校验、保存与恢复 |
| `src/style.css` | 页面和弹窗样式 |
| `tests/` | 引擎、关卡路线与存档测试 |

角色、场景、矿物、装饰和图标均由本项目的 Canvas、SVG 或 CSS 绘制，声音由 Web Audio 合成，无外部美术或音乐素材。游戏不包含联网账号、广告和在线排行。

## 验证与调整

引擎测试覆盖抓取与入账、炸药、精确截止时刻、重复结算、20 关无道具重放。存档测试覆盖损坏数据、范围校验、状态复制和存储受限。

[LEVEL_BALANCE.md](./LEVEL_BALANCE.md) 记录无道具保守通关路线，钱袋按最低收益计算。路线由程序精确瞄准验证，证明关卡可达；实际难度仍应结合玩家试玩调整。

GitHub Pages 使用相对资源路径，可在仓库子路径下运行。发布工作流位于 `.github/workflows/pages.yml`。
